DISCOVERY CODEX
Greedy decoding: always take the highest-probability token. Stable, but repetitive and incapable of exploring a lower-ranked alternative.

Temperature: divide logits by temperature before softmax. Lower values sharpen the distribution. Higher values flatten it and make unlikely tokens more reachable.

Top-k: keep only the k highest-logit tokens, renormalize, then sample. This can preserve variety while fencing off the long tail.

Sampling: draw one token according to the final probability distribution. Different random draws can produce different text from the same model state.

Boundary: this chapter uses a small fixed transition model so decoding behavior is isolated. Production systems may combine temperature with top-k, top-p, penalties, constraints, or deterministic decoding.
